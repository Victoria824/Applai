Applai 隐私政策

最后更新：2026-10-07

1. 我们收集什么数据

数据用途存储位置
求职画像（姓名、邮箱、电话、求职偏好等）自动填写申请表单、匹配合适职位你的浏览器本地 + 你注册账号的 Applai 服务器
简历文件自动上传到申请表单的简历栏；可选用于自动识别画像信息你的浏览器本地 + Applai 服务器（仅在你上传时）
账号信息（用户名、密码哈希）登录、多用户数据隔离Applai 服务器（密码仅存不可逆哈希）
投递记录（职位、状态、时间）在控制台展示你的投递进度Applai 服务器（仅你本人可见）

2. 我们不出售、不共享你的数据

你的画像、简历和投递记录不会出售、出租或分享给任何第三方。职位匹配调用的大语言模型（Qwen）仅接收脱敏后的职位描述与画像摘要用于打分，不会用于模型训练（以模型服务商政策为准）。

3. 权限说明

插件申请 <all_urls> 主机权限，是因为求职申请页分布在各公司官网（Greenhouse / Lever / Ashby / Workday 等不同域名），插件需要在你主动点击"自动填写"时读取并填写这些页面上的申请表单。插件不会在后台默默浏览或上传你的网页内容。

4. 你的权利

你可以随时在网页控制台删除投递记录、撤销 API Token；注销账号请联系开发者删除服务器端数据。

Applai Privacy Policy

Last updated: Oct 7, 2026

1. Data we collect

DataPurposeWhere stored
Job-seeker profile (name, email, phone, preferences)Autofilling application forms; matching suitable jobsYour browser (local) + the Applai server under your account
Resume fileAuto-attaching to resume fields; optional profile prefillYour browser + Applai server (only when you upload)
Account info (username, password hash)Login and per-user data isolationApplai server (passwords stored as irreversible hashes only)
Application recordsShowing your progress in the dashboardApplai server (visible only to you)

2. We do not sell or share your data

Your profile, resume and records are never sold, rented or shared with third parties. Job matching uses a language model (Qwen) that only receives job descriptions and profile summaries for scoring.

3. Why <all_urls> permission

Job applications live on many different company career sites (Greenhouse / Lever / Ashby / Workday). The extension needs host access to read and fill application forms on those pages when you click "autofill". It does not silently browse or upload your web content in the background.
