# Applai 朋友使用说明

> 给 Victoria 的朋友们：跟着这篇走，5 分钟开工。看不懂的直接问 Victoria。

## 它是干嘛的

Applai 是个自动求职小工具。你设好一次之后，它每天早上 8 点自动：
- 去 GTA/加拿大的招聘渠道找 IT 岗位（公司官网 ATS：Greenhouse / Lever / Ashby / Workday，外加 Job Bank 安省、Arbeitnow、Remotive）
- 用 AI 按你的画像给每个岗位打分，40 分以上的进投递队列
- Chrome 插件自动填表、自动附简历、自动提交；遇到验证码或填不了的，推到你手机上手动处理

## 三步开工

**第 1 步：注册**
点 Victoria 发你的邀请链接，注册一个账号（每个人的数据是隔离的，互相看不到）。

**第 2 步：画像 — 传简历**
进「画像」页，上传简历 PDF。系统会自动识别姓名、联系方式、目标岗位、年限等，
然后弹一个确认框：只补它没认出来的关键项（期望地点、薪资范围/时薪还是年薪、是否接受 remote、意向行业、工作许可）。点「确认保存」就行。

**第 3 步：插件 — 一键连接**
按 Victoria 发你的安装包把 Chrome 插件装上，然后在网页「插件」页点
「一键连接插件」。连上后插件才能代你填表投递。

## 每天它会做什么，你要做什么

- **你不用做什么**：每天 8 点（可在「定时」页改时间、改每天投几封）自动跑一遍：找岗 → 打分 → 投递。
- **你要看一眼的**：「待人工」— 验证码卡住的、Job Bank 的岗位（插件填不了 Job Bank 的表）会在这里，点一下手动投。
- **好消息会自动来**：面试邀请/拒信如果走了 Gmail（可选连接，见下），会自动更新申请状态，面试邀请直接手机推送。

## 页面速览

| 页面 | 干嘛的 |
|---|---|
| 首页 | 今日数据 + 求职 AI 助手（可以直接说"这周暂停投递"、"把 XX 公司加入队列"，它会执行） |
| 画像 | 你的简历和求职偏好；这里也能导出全部数据或删号 |
| 队列 | AI 打分 40+、等着自动投的岗位 |
| 待人工 | 需要你手动点一下的（验证码、Job Bank） |
| 历史 | 投过的记录，每条可看"投递快照"（当时投的 JD、填了啥、用的哪版简历） |
| 复盘 | 每周数据、回复率、AI 给的优化建议 |
| 定时 | 开关、投递时间、每天几封、手机通知开关 |
| 插件 | 连接插件、连接 Gmail、生成邀请链接 |

## 手机通知

在「定时」页点「开启手机通知」。iPhone 用户注意：要先把网站「添加到主屏幕」，再开通知才能收到。

## Gmail 连接（可选）

在「插件」页点「连接 Gmail」。**只读权限**：每 4 小时扫一次求职邮件，自动把"面试邀请"/"拒信"分类并更新你的申请状态。不会发邮件、不会删邮件。
⚠️ Victoria 还在配置 Google 授权，她说 OK 了你再连。

## 常见问题

- **每天投多少？我能控制吗？** 能。「定时」页调数量和时间；首页跟 AI 助手说"暂停投递"随时停。
- **它会乱投吗？** 只投 AI 打分 40+ 且符合你画像的；每条投递都有快照留痕，「历史」页可查。
- **我的数据安全吗？** 账号隔离；简历只存你自己的；「画像」页可一键导出 JSON 或彻底删号。
- **Job Bank 的岗位怎么投？** 自动发现和打分，但投递那步要你去 Job Bank 网站手动点一下，「待人工」里会提醒你。
- **我想换目标方向？** 改「画像」里的偏好，然后在「来源」页点"重新生成关键词"即可。
