# Victoria 发送邀请前检查清单

朋友点开链接后的体验，取决于这几件事有没有先做完。按顺序打勾：

## 1. 插件：你自己先重装
- [] Phase 1/Phase 2 都重打了插件 zip，你本地的还是旧版。去 `~/workspace/job-apply-tool/` 拿最新 zip，chrome://extensions 重新加载。
- [] 重装后打开 dashboard 刷新页面，确认「一键连接插件」状态正常。
- 为什么：你自己是"客服"，朋友遇到连接问题都来问你，你的必须是好的。

## 2. Gmail OAuth：先加测试用户，再让朋友连
- [] Google Cloud 那边走完：OAuth 客户端建好 → Client ID / Secret 给 Muse 设到服务器。
- [] **关键**：在 OAuth 同意屏幕的"测试用户"里，把你自己 + 每个朋友的 Gmail 都加上。应用没验证，只能测试用户用。
- [] 没加完之前，告诉朋友先**跳过**「连接 Gmail」那一步（walkthrough 里已经写了这句）。
- 为什么：没加测试用户，朋友点"连接 Gmail"会直接报无权限，体验翻车。

## 3. 生成邀请链接
- [] Dashboard「插件」页 →「邀请朋友」→「生成邀请链接」，一个链接可以发给所有人（每人注册自动关联）。
- [] 把链接填进 `invite-message.txt` 的位置，复制发微信群/私聊。
- [] 顺手把最新插件 zip 发群里。

## 4. 发完之后你能看到的
- Dashboard「邀请朋友」列表里，每个人的进度：●已注册 ●画像 ●简历 ●插件，谁卡在哪一步一目了然。卡住的人私聊推一把就行。
